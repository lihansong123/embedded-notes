## 提交规范

一条提交只说一件事，前缀固定（方便以后 `git log --oneline` 扫）：

| 前缀 | 用途 | 例子 |
|---|---|---|
| `weekNN:` | 某一周的学习内容 | `week01: 补时钟树 72MHz 配置步骤与口述稿` |
| `note:` | 笔记结构调整/纠错 | `note: 修正 GPIO 上拉下拉的 ODR 说明` |
| `review:` | 周复盘 | `review: 第1周复盘（卡在 HSERDY 死等）` |
| `chore:` | 仓库杂务 | `chore: 加 assets 目录` |

**每周至少 5 次提交**，不要周末一次性全推——绿色格子是给面试官看的活跃度证据。
